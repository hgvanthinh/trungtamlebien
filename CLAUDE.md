# Claude Instructions

## General Rules

- Luôn dùng tiếng Việt để trò chuyện/giải thích với người dùng (phần văn xuôi, mô tả, hỏi đáp). Không cần dịch 100% — giữ nguyên thuật ngữ lập trình, tên biến/hàm/file, lệnh, log, code và comment bằng tiếng Anh khi tự nhiên hơn.
- Do not run type-check or `tsc` after making code changes unless explicitly asked.
- Không tự chạy npm run build
